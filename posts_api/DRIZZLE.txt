# Drizzle ORM Migration & Utility Commands

Use these shorter project command workflows mapped via package execution scripts.

## Database Automation Lifecycle

### Schema Blueprint Compilation
Analyze schema structure updates and create physical tracking SQL assets:
```bash
npm run db:generate
```

### Direct Schema Prototyping Synchronization
Force instant code structure mirror synchronization actions to local target database binaries:
```bash
npm run db:push
```

### Sequential Historical Pipeline Migration
Safely execute historical generation migration folder assets step-by-step:
```bash
npm run db:migrate
```

### Programmatic Mock Data Seeding
Purge outdated data schemas and seed predictable relational entry records:
```bash
npm run db:seed
```

### Visual Studio Database Browser GUI
Launch the visual interactive web browser database management console panel:
```bash
npm run db:studio
```

### Internal Tracked State Removal Drop
Reset tracking systems or fix system drift discrepancies safely:
```bash
npm run db:drop
```

---

## Standard Run Workflow
To spin up a totally fresh developer database environment instance:
```bash
# 1. Sync structures
npm run db:push

# 2. Seed default data 
npm run db:seed

# 3. Run development web server
npm run start:dev
```
